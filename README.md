# Recflare Discord bot
A Recflare companion bot for getting stuff about Recflare in Discord.

# Getting started
To get started, download the project first from Github. Then, open a terminal in the folder you downloaded and run
```pip install -r requirements.txt```. Then clone config.toml.template and rename it config.toml, and fill out the config, with stuff like your bot token.

# Things to note
* The bot is still in development, and it's still being updated and worked on. If you have anything to add, make a pull request with your change. Please keep in mind it may take a bit for me to get to your PR.
* The documentation is limited due to still being worked on.
